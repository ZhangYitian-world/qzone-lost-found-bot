# 本机运行说明

## 启动、停止和重新登录

初始化参见 README。Python 主服务与只读桥接是两个进程，可分别运行：

```bash
zsh scripts/start.sh
data/bridge/node_modules/.bin/tsx scripts/bridge-server.mjs
```

停止在对应终端按 `Control+C`。数据库和队列保留，下次启动恢复未完成内容任务；未验证覆盖的采集轮次不推进成功时间。

实现上，程序读取单独保存的 QQ 空间网页 Cookie，不需要桌面 QQ 客户端常驻。退出客户端后，只要这份网页会话仍有效就能继续；腾讯是否因退出、密码修改、设备管理或风控而吊销会话，不由本程序控制，也没有据此承诺永久有效。当前没有自动执行真实退出登录的对照实验。

失效后相关来源自动暂停，在自己的终端运行：

```bash
data/bridge/node_modules/.bin/tsx scripts/bridge-server.mjs --login
```

使用专用小号完成正常登录。程序不解决验证码、不绕过权限拒绝。重新登录后重启只读桥接，检查会话，再在管理页重新启用来源；会从最后成功位置补齐。桥接令牌保存在 `data/bridge-token`，不需要手工复制进聊天。

## 本机网络兼容

如果电脑代理将腾讯 CDN 域名解析为 `198.18.0.0/15` 的 Fake-IP，可在确认 HTTPS 图片确实能正常下载后，将本机 `.env` 的 `MEDIA_ALLOW_FAKE_IP_DNS` 设为 `true`。默认模板为 `false`。

该选项仅对明确白名单域名的 Fake-IP 生效，不放行其他内网、回环地址、非 HTTPS、携带用户名密码的 URL 或重定向。切换到正常 DNS 的设备时可恢复 `false`。图片域名白名单可配置，发现未知域名先核实再加入。

## 模型、预算与异常

- `DEEPSEEK_API_KEY` 仅在服务端使用。保存 `.env` 后重启 Python 服务生效。
- 默认模型 `deepseek-flash`。图文能力和定价按实施日官方文档核对；未来模型或定价变化需重新核对。
- 默认预算每天 5 元，北京时间跨日重置统计。每次调用前预留 0.3 元；按当前保守单价检查输入与最大输出上限，超过预留时拒绝调用。
- 成功返回按令牌量结算估算费用；无效 JSON 也产生费用并计量。超时或缺少 usage 时保留预留，避免把未知成本视作免费。
- 模型最多自动尝试两次，图片最多四次；失败任务可手工重试。图片缺失时禁止交接，待补抓任务不会因为列表已覆盖而被丢弃。
- 连续两轮采集失败、内容等待超过 10 分钟、预算不足或交接多次未确认，在运行概览显示告警。

价格估算刻意按非缓存峰时价格乘保守人民币系数，不等于服务商实时账单。不做自动充值。

## 数据、备份与到期清理

`data/` 限当前用户访问，`.env`、会话和本地导出文件使用 0600 权限。普通日志不记录原文、完整身份字段、Cookie 或 Key。

服务每日执行一次保留检查：原文、旧原文版本及图片默认 30 天；到期证据使旧线索撤回，进入待核实。关闭事件的结构化信息及对应人工记录默认 90 天。保留期限上线前仍需与下游确认。

备份前暂停服务，复制 SQLite 数据库与 `data/media/`，单独安全保存 `.env` 与会话目录；不要公开备份。`data/demo-consumer.sqlite3` 是本地模拟下游的独立副本，其保留和清理与正式下游一样需要单独管理。

## 实际获取方式的限制

第三方 SDK 固定上游提交 `e2c6da0ffea8937adac690352647bb023c312759`。原 `getPostsStrict` 路径实际使用过滤后的好友动态流；本机探测到其游标续翻返回认证失败，因此目前门面改用已经授权且可见的**个人空间动态页** `getFeedsHtmlActAll(hostUin=目标账号)`，不暴露任意账号读取。

本地补丁：关闭上游原始日志，保留 Chrome 沙箱，取消个人动态页解析结果的不安全截断。上游可能解析出额外的置顶记录，按 ID 去重比截断丢弃更安全。依赖已使用锁文件固定，实施时 npm 审计为 0 项已知问题；这不是长期安全保证。

偏移分页无法提供稳定快照。每轮固定时间上限，重读起点前 10 分钟，遍历到更早的完整页或确认末页，再重扫比较内容标识。遇到移动、不一致、空响应、缺字段等，成功截止时间保持不变。迟到超过恢复窗口的旧内容、采集前已删除或不可见的内容不保证发现。

同条动态去重自动完成。跨来源仅在原帖引用明确、正文与媒体一致、人物物品对应一致时自动合并；其余由操作者核实合并，仅姓名或物品相同绝不自动合并。已合并的来源出现变化时保留新识别建议并转核实。独立新发的“已归还”若不能明确定位旧事件，需要操作者关联并关闭原事件。P1 评论补充暂未接入，避免扩展到整个好友圈或全部历史评论。
