## 实施中发现并处理的问题

1. 原候选 `getPostsStrict` 路径使用过滤后的好友动态流，续翻返回认证失败。保留错误结论，改为同一授权会话下实际可见的个人动态页，不把失败当成无新增。
2. 动态页可返回额外置顶条目，上游按条数截断有丢弃风险。本地补丁保留全部解析记录，交由稳定标识去重。
3. 图片访问签名随时间变化，导致误判编辑。本地内容摘要忽略明确的临时签名参数，并刷新下载地址，实际图片资源变化仍产生版本。
4. 本机代理使用 Fake-IP DNS；在明确腾讯 CDN 域名白名单下增加局部兼容，其他内网地址仍被拒绝。
5. 模型可能更换同一事件的临时键。持久事件标识由本地核对维持，分类变更、已归还及重跑不依赖模型临时命名。
6. 模型首次无效输出进入重试，二次输入强调文字/图片证据来源；仍失败则留错误任务。没有把识别失败当成无失物。
